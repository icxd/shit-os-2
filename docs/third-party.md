# Third-party content

shit os 2 is written from scratch. This is the complete list of content in the
tree that is not, kept short deliberately.

## Terminus (bitmap font)

`kernel/dev/font8x16.h` is generated by `tools/genfont.py` from
`Lat15-Terminus16.psf`, part of the Terminus font by Dimitar Zhekov.

Terminus is licensed under the **SIL Open Font License 1.1**, which is
compatible with the GPLv3 the rest of the project uses. The generated header
contains the first 128 glyphs (ASCII) as raw bitmaps.

- Upstream: <https://terminus-font.sourceforge.net/>
- License: <https://openfontlicense.org/>

To regenerate, with a PSF font available at the path in the script:

```sh
python3 tools/genfont.py
```

For completeness, since these shape the code without contributing any:
multiboot2, the System V x86-64 ABI and ELF64, the Intel and AMD manuals,
POSIX.1, and the ustar format from POSIX.1-1988.
